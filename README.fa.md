# کورلی (Corely) — داشبورد شخصی و هوشمند

**Corely** یک داشبورد شخصی مدرن، سریع و همه‌جانبه با طراحی راست‌چین (RTL) و سبک الهام‌گرفته از ویندوز ۱۱ (Fluent) است. این اپلیکیشن به شما امکان می‌دهد تمام کارهای روزمره، عادات، ایده‌ها، امور مالی، فایل‌ها و یادداشت‌های خود را در یک محیط زیبا، یکپارچه و امن مدیریت کنید.

---

## 🧭 پنل‌های اصلی سایدبار

1. **خانه (`Home`):**
   - ساعت دیجیتال دقیق به همراه تقویم شمسی و میلادی.
   - برنامه امروز و چک‌لیست روتین روزانه.
   - تایمر تمرکز پومودورو (Pomodoro).
   - دسترسی سریع به کارهای روزمره (To-Do)، لیست خرید و عادات.
   - خلاصه دخل‌وخرج ماهانه و اهداف پس‌انداز.
   - دستیار هوشمند سریع در صفحه اصلی.

2. **دستیار هوشمند (`AI Assistant`):**
   - چت و مشاوره با مدل‌های هوش مصنوعی با چند رشته گفتگوی مجزا (Multi-Thread).
   - رندر کامل متون مارک‌داون (Markdown): عنوان، فهرست، بلوک کد، متن پررنگ و مورب، لینک و نقل‌قول.
   - قابلیت‌های **Function Calling** جهت ثبت خودکار تسک‌ها، لیست خرید، برنامه هفتگی، تراکنش‌های مالی و یادداشت‌ها توسط هوش مصنوعی.

3. **یادداشت‌ها (`Notes`):**
   - ویرایشگر متنی مینیمال با ذخیره‌سازی خودکار آنی، شمارندهٔ کلمات و کاراکترها، و قابلیت کپی/دانلود فایل.
   - بخش کارت‌های یادداشت چسبان (Stickies) رنگارنگ با قابلیت پین‌کردن و جستجو.

4. **ایده‌ها (`Ideas`):**
   - ثبت و دسته‌بندی ایده‌ها بر اساس وضعیت (شروع‌نشده، در حال انجام، تکمیل‌شده).
   - امکان افزودن بی‌نهایت لینک وب، پیوست فایل و تصاویر با گالری اختصاصی و لایت‌باکس تمام‌صفحه.

5. **منابع ادیت (`Edit Assets`):**
   - مخزن سازمان‌دهی منابع تدوین و ادیت ویدیو (صداها، ویدیوهای خام، میم‌ها، افکت‌ها و تصاویر).
   - **کتابخانه‌ی پیوندی:** فایل‌ها کپی نمی‌شوند. همان‌جا که روی دیسک هستند می‌مانند و Corely فقط مسیرشان را به خاطر می‌سپارد؛ پس حتی ویدیوهای بسیار حجیم تقریباً هیچ فضای اضافه‌ای نمی‌گیرند. فایل‌ها از طریق پنجره‌ی انتخاب فایل/پوشه‌ی سیستم اضافه می‌شوند.
   - برای هر فایل یک پیش‌نمایش کوچک ساخته می‌شود و هنگام اسکرول به‌صورت تنبل بارگذاری می‌شود (لیست ۴۸ تا ۴۸ تا نمایش داده می‌شود).
   - اگر فایل پیوندی جابه‌جا، تغییر نام یا حذف شود، با برچسب «فایل پیدا نشد» نشان داده می‌شود و می‌توانید آن را تکی یا با انتخاب پوشه‌ی جدیدش دوباره پیوند بزنید.
   - **دسته‌بندی‌ها:** در تب‌های ویدیو، صدا و تصویر «همه» یا «دسته‌بندی» را انتخاب کنید؛ دسته‌ها مثل پکیج به‌صورت کارت نشان داده می‌شوند و می‌توانید دسته‌ی دلخواه اضافه یا حذف کنید. دسته‌بندی هنگام افزودن فایل پرسیده می‌شود.
   - **پکیج‌ها:** منابع را در پکیج دسته‌بندی کنید (ساخت، تغییر نام، حذف)، از روی کارت‌ها فایل را مستقیم به پکیج اضافه کنید، یا از یک پوشه روی دیسک پکیج بسازید. هر منبع حداکثر در یک پکیج است.
   - دسته‌بندی، بوکمارک و پخش درون‌برنامه‌ای (با پشتیبانی از جلو و عقب بردن ویدیو). قالب‌هایی که Chromium پخش نمی‌کند (مثل HEVC، ProRes و بعضی mkv/avi) پیش‌نمایش و پخش داخلی ندارند و با برنامه‌ی پیش‌فرض سیستم باز می‌شوند.
   - پسوندهای مجاز: ویدیو (mp4، webm، mov، mkv، avi، m4v)، صوت (mp3، wav، ogg، m4a، flac، aac)، تصویر (png، jpg، jpeg، gif، webp، bmp، avif). فایل svg عمداً مجاز نیست.

6. **مدیریت مالی (`Finance`):**
   - ثبت و تفکیک تراکنش‌های درآمد و هزینه به همراه دسته‌بندی هوشمند.
   - گزارش‌گیری و ناوبری ماهانه با محاسبه خودکار موجودی.
   - تعریف اهداف پس‌انداز (Savings Goals) با نوار پیشرفت و پین کردن کارت‌های هدف.

7. **دانلود منیجر (`Downloads`):**
   - ثبت و مدیریت لینک‌های دانلود با دسته‌بندی (ویدیو، موزیک، تصویر، سند، نرم‌افزار).
   - نمایش سرعت، نوار پیشرفت، حجم مصرفی و وضعیت هر دانلود.

8. **تغییر دی‌ان‌اس (`DNS Changer`):**
   - مرجع و تنظیمات سریع سرورهای DNS ضدتحریم (شکن، الکترو و...) و سرویس‌های بین‌المللی پایدار (کلودفلر، گوگل و...).
   - تست و راهنمای اعمال تنظیمات در سیستم‌عامل.

9. **تنظیمات (`Settings`):**
   - تب‌ها: عمومی، دستیار هوشمند، ظاهر، پشتیبان‌گیری، اعلان‌ها، آمار سیستم.
   - تنظیمات نام کاربری، زبان (پیش‌فرض انگلیسی، فارسی راست‌چین)، افکت‌های صوتی و گزینه‌ی «مخفی‌سازی پیش‌فرض مبالغ مالی» (حالت حریم خصوصی).
   - تنظیم سرویس‌دهنده هوش مصنوعی (Google Gemini یا سرویس‌های سازگار با OpenAI)، کلید API و پروکسی.
   - تهیه فایل پشتیبان (JSON) و بازیابی داده‌ها و تصاویر (بخش «پشتیبان‌گیری سبک» را در پایین ببینید).

## 🔎 جستجوی سراسری

با `Ctrl+K` (یا دکمه‌ی ذره‌بین پایین سایدبار) می‌توانید در خود بخش‌ها و تنظیمات اپ (مثلاً با نوشتن «زبان» می‌بینید کجا عوض می‌شود) و هم‌زمان در ایده‌ها، یادداشت‌ها (خط‌به‌خط)، کارها، لیست خرید، منابع ادیت، پکیج‌ها و اطلاعات مالی جستجو کنید. حروف فارسی/عربی، نیم‌فاصله و اعداد نرمال‌سازی می‌شوند و در حالت حریم خصوصی، مبالغ با ستاره پنهان می‌شوند. با انتخاب هر نتیجه به بخش مربوط می‌روید.

## ✨ ویژگی‌های کلیدی

- **طراحی دو تم اختصاصی:** تیره (`Dark`) و روشن (`Light`) با رنگ‌بندی چشم‌نواز و بدون خستگی چشم.
- **دوزبانه (پیش‌فرض انگلیسی و فارسی راست‌چین):** پشتیبانی کامل از زبان‌های انگلیسی (چپ‌چین، پیش‌فرض برای نصب‌های جدید) و فارسی (راست‌چین).
- **تقویم شمسی بومی:** تبدیل ریاضی و دقیق تاریخ میلادی به هجری خورشیدی بدون کتابخانه‌های سنگین.
- **آفلاین‌فرست و امنیت داده:**
  - اطلاعات متنی و تنظیمات روی حافظه محلی داخل اپلیکیشن (`localStorage`) روی همان دستگاه ذخیره می‌شوند.
  - تصاویر، پیوست‌ها و پیش‌نمایش‌ها در پایگاه داده داخلی `IndexedDB` برنامه روی همان دستگاه ذخیره می‌شوند تا به سقف حجم حافظه برخورد نکنند. فایل‌های رسانه‌ای حجیم «منابع ادیت» اصلاً کپی نمی‌شوند: روی دیسک خودتان می‌مانند و فقط پیوند داده می‌شوند.
  - هیچ سرور یا ردیابی از سمت Corely وجود ندارد و داده‌های شما روی همین دستگاه می‌مانند. تنها استثنا دستیار هوشمند است: وقتی از آن استفاده می‌کنید، پیام شما و تاریخچه چت (به‌همراه اطلاعات زمینه‌ای که همراه پیام فرستاده می‌شود) مستقیماً برای سرویسی که خودتان تنظیم کرده‌اید (Gemini یا سرویس سازگار با OpenAI) ارسال می‌شود.
- **پشتیبان‌گیری سبک JSON:** امکان دانلود داده‌های متنی و تصاویر IndexedDB در یک فایل JSON و بازیابی آن. فایل‌های رسانه‌ای پیوندی هرگز در بکاپ نیستند (فقط فهرست و پیش‌نمایش‌های کوچک)، پس بعد از بازیابی روی دستگاه دیگر باید فایل‌ها را دوباره پیوند بزنید. از استور رسانه فقط پیش‌نمایش‌ها و رکوردهای تا ۱ مگابایت وارد بکاپ می‌شوند؛ رکوردهای بزرگ‌تر رد می‌شوند و برنامه تعداد آن‌ها را اعلام می‌کند. بازیابی فقط به استور رسانه اضافه می‌کند و آن را پاک نمی‌کند. کلیدهای محرمانه API در فایل پشتیبان قرار نمی‌گیرند.
- **مرز خطای هوشمند (Error Boundary):** جلوگیری از سفید شدن صفحه هنگام خطاهای احتمالی، با دکمه‌های تلاش مجدد و مشاهده جزئیات فنی.

## 🤖 راه‌اندازی دستیار هوشمند (AI Assistant Setup)

ارتباط با هوش مصنوعی در Corely مستقیماً از طریق IPC در پردازش اصلی Electron و بدون نیاز به هیچ سرور واسط انجام می‌شود:

- **کلید اختصاصی کاربر (BYOK):** هر کاربر کلید API اختصاصی خود را در مسیر **تنظیمات > دستیار هوشمند** وارد می‌کند.
- **سرویس‌های پشتیبانی‌شده:**
  - **Google Gemini:** استفاده از SDK رسمی و مدرن `@google/genai`.
  - **سازگار با OpenAI (OpenAI-Compatible):** اتصال به هر سرویس‌دهنده مبتنی بر API استاندارد OpenAI (مثل OpenRouter، Groq یا مدل‌های محلی) با وارد کردن آدرس پایه (Base URL)، کلید API و شناسه مدل (Model ID).
- **ذخیره‌سازی امن محلی:** کلید API فقط روی دستگاه شما ذخیره می‌شود و هرگز به سرورهای واسط فرستاده نشده و در فایل پشتیبان خروجی هم قرار نمی‌گیرد.
- **ارتباط مستقیم با سرویس‌دهنده:** پیام‌ها، تاریخچه گفتگو و زمینه پیام فقط مستقیماً به سرویسی که خودتان تنظیم کرده‌اید (Gemini یا سرویس سازگار با OpenAI) ارسال شده و از هیچ سروری از سمت Corely عبور نمی‌کند.
- **حل خطای 403 Forbidden:** در صورتی که به دلیل محدودیت‌های منطقه‌ای با خطای ۴۰۳ مواجه شدید، دو راهکار وجود دارد:
  1. استفاده از وی‌پی‌ان سراسری سیستم (حالت TUN).
  2. در بخش **تنظیمات > عمومی > پروکسی برنامه**، کلید را روشن کرده و آدرس پروکسی HTTP برنامه وی‌پی‌ان خود را وارد کنید (مثلاً `http://127.0.0.1:10808`). فعلاً این پروکسی فقط برای درخواست‌های هوش مصنوعی استفاده می‌شود. در صورت خاموش یا خالی بودن، ارتباط به شکل مستقیم برقرار می‌شود.

## 🪟 نکات مربوط به ویندوز (Windows Notes)

- **دسترسی ادمین برای تغییر DNS:** تغییر آدرس DNS کارت شبکه در ویندوز نیازمند دسترسی ادمین است. Corely این کار را با یک بار تایید پنجره UAC در هر اجرای برنامه از طریق هلپر اختصاصی (`electron/dns-helper.cjs`) انجام می‌دهد. با بستن برنامه، این هلپر پس‌زمینه نیز به طور خودکار بسته می‌شود.
- **سیستم تری (System Tray):** با بستن پنجره اصلی، Corely بسته نمی‌شود بلکه به System Tray ویندوز منتقل می‌گردد تا در پس‌زمینه در دسترس بماند.
- **اجرا با استارتاپ ویندوز:** اجرای خودکار با روشن شدن سیستم کاملاً اختیاری است و فقط در صورت تمایل کاربر از بخش تنظیمات فعال می‌شود.
- **عدم نوشتن لاگ روی دیسک:** هیچ فایل لاگ، گزارش یا تلمتری اضافی روی دیسک سیستم شما ذخیره نمی‌شود.

## 🛡️ امنیت (Security)

- **ایزوله‌سازی فرآیند دسکتاپ:** الکترون با تنظیمات امنیتی `contextIsolation: true`، `sandbox: true` و `nodeIntegration: false` اجرا می‌شود.
- **بررسی مبدأ درخواست‌های IPC:** هندلرهای IPC به دقت مبدأ فرستنده پیام را اعتبارسنجی می‌کنند تا فقط درخواست‌های ناشی از پروتکل داخلی و معتبر `app://corely` پردازش شوند.
- **سیاست امنیت محتوا (CSP):** یک Content Security Policy مشخص می‌کند اسکریپت‌ها، استایل‌ها و محتوای شبکه از چه منابعی می‌توانند بارگذاری شوند.
- **باز شدن امن پیوندهای خارجی:** تمام لینک‌های بیرونی رهگیری شده و به صورت امن در مرورگر پیش‌فرض سیستم‌عامل کاربر باز می‌شوند (`shell.openExternal`).
- **بدون سرور محلی و پورت باز:** برنامه مستقیماً از فایل‌های بسته‌بندی‌شده از طریق پروتکل سفارشی `app://corely/` بارگذاری می‌شود و هیچ سرور Express، پورت شبکه باز یا سوکت محلی ایجاد نمی‌کند.

## 🛠️ استک فنی

- **فرانت‌اند:** React 19 + TypeScript
- **ابزار ساخت:** Vite
- **معماری دسکتاپ:** Electron (ارتباط امن با IPC بدون سرور محلی؛ پروتکل اختصاصی `app://corely`)
- **استایل‌دهی:** Tailwind CSS v4
- **انیمیشن‌ها:** Motion (Framer Motion)
- **آیکون‌ها:** Lucide React
- **هوش مصنوعی:** Google GenAI SDK (`@google/genai`) و سرویس‌های سازگار با OpenAI با پروتکل امن `undici` و قابلیت اتصال از طریق پروکسی HTTP اختیاری

## 🌐 سرویس‌های خارجی مورد استفاده

Corely فقط برای چند قابلیت مشخص به اینترنت و سرویس‌های خارجی متصل می‌شود. فقط فایل‌های ثابت دریافت می‌شوند و داده‌ی شما ارسال نمی‌شود، اما سرور مقصد (مثلاً گوگل برای فونت) ممکن است آدرس IP شما را ببیند:

- **فونت Vazirmatn:** از Google Fonts (`fonts.googleapis.com`) بارگذاری می‌شود. در صورت نبود اینترنت یا فیلتر بودن، اپ به فونت پیش‌فرض سیستم بازمی‌گردد و از کار نمی‌افتد.
- **حذف پس‌زمینه‌ی تصاویر:** کتابخانه‌ی `@imgly/background-removal` مدل هوش مصنوعی مورد نیاز خود را در لحظه‌ی استفاده از `staticimgly.com` دانلود می‌کند.

## 🚀 راهنمای نصب و اجرا

### پیش‌نیازها
- نصب بودن Node.js (نسخه ۲۰ یا بالاتر؛ با توجه به پیش‌نیاز وابستگی‌های مدرن از جمله `undici`)

### ۱. نصب وابستگی‌ها
```bash
npm install
```

### ۲. پیش‌نمایش رابط کاربری در مرورگر (Vite)
```bash
npm run dev
```
سرور توسعه محلی Vite برای پیش‌نمایش سریع رابط کاربری در مرورگر اجرا خواهد شد (توجه: قابلیت‌های اختصاصی دسکتاپ مانند هوش مصنوعی از طریق IPC و تغییر DNS فقط در محیط Electron کار می‌کنند).

### ۳. اجرای نسخه دسکتاپ (محیط توسعه)
```bash
npm run electron:dev
```
کدها را بیلد کرده و اپلیکیشن کامل دسکتاپ را درون Electron اجرا می‌کند.

### ۴. ساخت نسخه نهایی فرانت‌اند (Production Build)
```bash
npm run build
```
کدهای رابط کاربری را کامپایل کرده و در پوشه `dist/` قرار می‌دهد.

### ۵. ساخت بسته نصبی ویندوز (Windows Installer)
```bash
npm run dist:win
```
فایل نصبی ویندوز (`.exe`) را به کمک `electron-builder` می‌سازد. (توجه: وجود آیکون معتبر در مسیر `build/icon.ico` برای ساخت فایل نصبی ضروری است).
